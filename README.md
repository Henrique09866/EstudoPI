# Estudo Pi

Aplicativo Flutter offline para organizar tarefas e acompanhar estudos.

## Recursos

- tarefas com matérias, categorias, prioridades e lembretes locais;
- busca, filtros, calendário e recorrência;
- Modo Estudo com Pomodoro 25/5 e cronômetro livre;
- sessões persistidas, meta diária e acompanhamento de progresso;
- funcionamento local com Hive, sem conta ou conexão com internet.

## Plataformas

- Android;
- Windows;
- Linux.

No Android, lembretes são agendados com notificações locais. No Windows, o suporte depende das capacidades oficiais do plugin e pode ter limitações de empacotamento. No Linux, notificações imediatas são suportadas, mas o agendamento futuro tem limitações.

## Executar

```bash
flutter pub get
flutter run
```

## Testes

```bash
flutter analyze
flutter test
```
